Google Sheet for orders

VineTools can add your orders to a Google Sheet (the DASHBOARD tab of your "Reviews" workbook): date, order number, picture, status ORDERED, title, ETV. Rows are added in the first empty row with the same formatting and dropdowns as the row above, only the columns it knows are written, and an order number already on the sheet is never added twice. Try it on a copy of your sheet first.

Sign-in needs the extension's Google client ID to be set up (see docs/GOOGLE_INTEGRATION.md).
