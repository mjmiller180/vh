Sync with a folder (Google Drive)

Keeps your settings, hidden items and pinned items in one file, vinesmyths-sync.json, inside a folder you choose. Pick a folder inside your Google Drive for desktop (e.g. G:\My Drive\Amz Vine\Sync) and every computer pointing at that folder stays in step. The extension only reads and writes that one file; Google Drive's own app does the uploading. No other server is involved.

Merging: hide/pin/un-hide/un-pin on any computer is combined (the most recent action on an item wins). For settings, the computer that changed them last wins (keep your computers' clocks roughly correct). A brand-new computer takes the file's settings. Device-specific values (country, usage counter, encryption keys) are never shared.

The file includes your Discord webhook URLs, so keep the folder private.
