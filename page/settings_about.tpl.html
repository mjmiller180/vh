About this build

This is a stripped-down, local-only build of Vine Helper 3.8.7. It does not contact Vine Helper's servers or any third party. The only network traffic it adds to Amazon's own is the post to your Discord webhook, if you turn that on. Community features that depended on Vine Helper's server (shared ETVs, order statistics, variants, reviews, the notification monitor) have been removed.
