Messages are posted straight from the extension to your own Discord webhook. Nothing goes through any other server. Only discord.com / discordapp.com webhook URLs are accepted. Each item is sent only once per trigger (reloading the page will not send it again).

In Discord: Channel settings > Integrations > Webhooks > New Webhook > Copy Webhook URL. The URL is hidden while typing; hover the field to reveal it.

Message placeholders: $QUEUE_NAME $TITLE $IMG_URL $ASIN $VH_URL $VINE_SEARCH_URL $AMZ_URL $KEYWORD $ETV. The message must stay valid Discord webhook JSON.

Keyword match

When an item title matches one of your highlight keywords (Keywords tab).

New item in AFA (Additional items for all)

Every item you see while browsing the AFA queue.

New item in RFY (Recommended for you)

Every item you see while browsing the RFY queue.

Zero ETV

When an item's ETV is known to be $0. Without Vine Helper's server, an ETV is only known after you reveal it (open the item's details), so this fires then.

Manual button on each item

Adds a Discord button to every item's toolbar to send that item whenever you want.
