Version {{$appVersion}} change notes:
This update fix some bug, but mainly introduce the ability to choose between the WebSocket connection being created and held by the Service Worker or the Monitor Tab itself. The later option is now the new default, and should help avoid unwanted connection from devices not actively using the monitor. Service Worker mode (the old default) is still available as it provide a more stable connection on devices with a battery optimization system.

Note that new Tier3 features are still Beta and may not work as expected.


Change log:

General:

  • NEW: Ability to select the WebSocket connection mode betwee Service Worker (SW) or Tab Mode (Tab). Service Worker is a more resillient connection, but will be established regardless if the monitor is opened or not. Tab mode will attach the connection to the Monitor Tab (the Master tab) and will only connect if the monitor is opened. Tab mode is more prone to be put to sleep by battery optimization systems.
  • CHANGE: Defaulting websocket connection mode to Tab Mode as many people reported having issues with unwanted device establishing a connection.
  • FIX: Keywords testing tool was not working correctly.
  • FIX: Keyword with 0 ETV max value would not match items with 0 ETV.

Notifications Monitor:

  • NEW: Long pressing the Fetch Last button will display additional options to fetch less items.
  • FIX: Keyboard shortcuts were working in the notifications monitor when they should not.

Premium feature(s):

  • NEW: Tier3: If available, display Amazon prices and thumbnails carousel to display additional images (Beta)
  • NEW: Tier3: Advanced hooks content (Beta)
  • NEW: Tier3: 0ETV hook (Beta)
  • New: Tier2: ETV modifier to display ETVs according to your tax rate.
